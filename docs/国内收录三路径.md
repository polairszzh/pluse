# 国内收录三路径与平台生态位（B5）

> Updated: 2026-08-11

## 为什么查收录

国内 AI（DeepSeek/Kimi/豆包/元宝等）没有公开爬虫，靠百度、搜狗、博查等索引喂数据。
对个人创作者，「内容是否被这些索引收录」比 robots.txt 有用得多——没收录就没有后续的
被 AI 引用。`python scripts/search_ai.py --index-check <URL>` 用 `site:` 探测检查单篇内容在 Bing/百度的收录状态。

## 三路径

1. **百度收录**：最核心的国内索引。百度收录的内容才可能进入文心/百度系生态及多数国内 AI 的检索池。
   - 检查：`site:<域名>` 或 `site:<完整URL>` 在百度/必应搜索。
   - 加速：知乎/百家号等百度权重高的平台发布；文章被站内引用/转载。
2. **搜狗收录**：微信生态入口（公众号文章主要靠搜狗）。腾讯系（元宝）对公众号内容亲近。
   - 检查：搜狗 `site:` 探测（当前 B5 MVP 未接入，待排期）。
3. **博查（Bocha AI）检索**：面向 AI 的检索服务，部分国产模型用它拼装检索结果。
   - 检查：博查站内收录探测（待排期）。

## 各平台生态位（实测引用源权重，2026）

| AI 平台 | 主要信源 | 内容策略 |
|---|---|---|
| DeepSeek | CSDN(24.6%)、知乎(19.8%)、博客园(15.3%) | 技术深度 + 可验证数据，偏好老内容（14-28 天） |
| 豆包 | 头条(35.2%)、知乎(21.8%)、抖音生态 | 场景化实用内容，时效敏感（4-7 天见效） |
| 通义千问 | 搜狐号(28.7%)、网易号(19.4%)、知乎 | 媒体化、口语化 |
| 文心一言 | 百家号(41.3%)、百度知道、百度百科 | 百度系生态优先，查百度收录最相关 |
| 元宝 | 微信生态（公众号）、腾讯新闻 | 时效性最强（71% 一年内新内容） |

## 判断优先级

个人创作者的「求收录」优先顺序：目标平台的信源生态位 → 该生态的收录路径。
例如想被 DeepSeek 引用 → 内容发知乎/CSDN + 确认百度收录；想被豆包引用 → 头条/知乎 + 头条系收录。
